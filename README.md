# introducejobs 🚀

A community-updated board of startup job openings across Indian cities — maintained like an open-source repo, not a static list.

**How this works:**
- All listings live in [`jobs.yaml`](./jobs.yaml) — the single source of truth
- This README's table is auto-generated from that file (don't hand-edit the table below)
- Anyone can contribute a listing — see **How to Add a Job** below

---

## How to Add a Job

**Option A — No GitHub experience needed:**
Open a new [Job Submission Issue](../../issues/new/choose) and fill in the form. It'll be reviewed and merged into the board.

**Option B — Comfortable with GitHub:**
1. Fork this repo
2. Add your listing as a new entry in `jobs.yaml`
3. Open a Pull Request

Either way, listings are reviewed before going live — this keeps the board clean and spam-free.
